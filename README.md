# My React App

This project was bootstrapped with [Create React App](https://github.com/facebook/create-react-app).

## Available Scripts

Run the following commands from the project root:

### `npm start`

Starts the app in development mode.
Visit [http://localhost:3000](http://localhost:3000) to view it in your browser. The page hot-reloads on file changes, and lint errors appear in the console.

### `npm test`

Launches the test runner in interactive watch mode.
See the [running tests](https://facebook.github.io/create-react-app/docs/running-tests) docs for details.

### `npm run build`

Bundles the app for production into the `build` folder.
React is compiled in production mode and output files are minified with hashed filenames — ready to deploy.

### `npm run eject`

> ⚠️ **This is irreversible.** Once ejected, you cannot go back.

Ejects the build configuration out of `react-scripts` and into your project, giving you full control over Webpack, Babel, ESLint, and more. Only use this if the default setup no longer meets your needs.
